# Front (`apps/web`) : documents de référence

Ce dossier réunit les documents visuels et de contenu utilisés pour construire le site. Pour le contrat API, voir [`docs/api-front.md`](../api-front.md) — il fait foi sur tout ce qui concerne les routes, pas les documents ci-dessous, qui datent d'avant la livraison de certaines d'entre elles (catalogue, fichiers).

- [`brief.md`](brief.md) — brief de conception : pages, design system, contenu et ton, sécurité, à faire par phase. **Lire en premier.**
- [`maquette/maquettes-boutique.html`](maquette/maquettes-boutique.html) — les ~30 écrans, cliquable comme un prototype. À ouvrir dans un navigateur (connexion internet nécessaire pour les polices). Référence visuelle : reproduire en composants Next.js, ne pas recopier le HTML.
- [`charte/`](charte/) — jetons de design (`jetons/fondamental-jetons.css` et `.json`), icônes SVG (`icones/interface/`, `icones/plugins/`), logo (`logo/`), charte complète (`charte/charte-fondamental.pdf`).
- [`rapport-plugins/`](rapport-plugins/) — analyse du code des 4 plugins (tableaux Gratuit/Premium, prérequis, versions, identifiants de licence). Référencé par le brief pour tout ce qui doit être exact plutôt qu'approximatif.

La feuille de route par phases est dans l'issue [#58](https://github.com/gladiaaa/fondamentalPlugin/issues/58).
