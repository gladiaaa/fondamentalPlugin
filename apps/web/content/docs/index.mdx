## Prérequis communs

- Serveur **Paper 1.21.4** ou plus récent (les plugins ciblent Minecraft 1.21).
- **Java 21**.
- Les dépendances propres à chaque plugin sont listées sur sa page d'accueil.

Une question qui n'est pas traitée ici ? Passez par la page [Support](/support).
