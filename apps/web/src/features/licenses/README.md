# `features/licenses`

Espace client : mes licences, installations, libération (`/compte/licences`, `/compte/licences/[id-interne]`). Routes livrées (#25, #45, #91) : `lib/api/account.ts` (liste, rattachement) et `lib/api/licenses.ts` (détail, libération). Clé masquée par défaut ; identifiant interne dans l'URL, jamais la clé complète (brief §10).
